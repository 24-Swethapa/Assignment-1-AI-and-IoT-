# Assignment 1 – AI and IoT

## IoT Sensor Data Analysis

This project analyzes an IoT-related dataset using Machine Learning techniques.

### Dataset
- Dataset: Combined Cycle Power Plant Dataset
- File: Folds5x2_pp.xlsx
- Attributes: AT, V, AP, RH
- Target: PE (Net hourly electrical energy output)

### Tasks Performed
1. Dataset loading and exploration
2. Missing value handling
3. Numerical and categorical attribute identification
4. Feature selection
5. Regression using Linear Regression
6. Regression evaluation using MAE, MSE and R²
7. Binary classification of energy output
8. Classification using Logistic Regression
9. Classification evaluation using Accuracy, Precision, Recall and F1-score

### Files
- `IoT_sensor_data_analysis.ipynb` – Google Colab notebook
- `Folds5x2_pp.xlsx` – Original dataset
- `Folds5x2_pp.csv` – CSV version of the dataset
